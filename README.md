# Mohammed Rizwan — Personal Portfolio

A modern, cinematic personal portfolio website for **Mohammed Rizwan**, a Software Developer & System Administrator.

The portfolio showcases my skills, projects, experience, and contact information through a dark, editorial-inspired interface with smooth animations and responsive design.

## ✨ Features

- 🎨 Cinematic dark portfolio design
- 👤 Personal profile section
- 🖼️ Custom profile logo and profile image
- 💻 Selected projects showcase
- 🔗 Live demo links for projects
- 🛠️ Technical skills section
- 📊 Project statistics
- 📱 Fully responsive design
- ✨ Smooth scroll and reveal animations
- 🎯 Interactive project cards
- 📧 Direct email contact
- 🔗 GitHub, Instagram and LinkedIn links
- ⚡ Fast and lightweight frontend
- ☁️ Cloudinary-hosted images
